# SocialMCP plugin for Grok Build 

Connect Grok Build to [SocialMCP](https://social-mcp.finepher.com) to manage
social accounts through its hosted MCP server.

## Installation

In Grok Build, open `/plugin`, search for **SocialMCP**, and install. Sign in
through the browser when prompted, then connect the social accounts you want
to use in SocialMCP.

## Capabilities

SocialMCP supports LinkedIn, Facebook Pages, Instagram professional accounts,
X, YouTube, TikTok, Reddit, Pinterest, and Threads. Available networks depend
on which integrations are configured by SocialMCP.

Posts wait for your approval by default. SocialMCP lets you change approval
settings per account.

## Connection

The plugin connects to `https://social-mcp.finepher.com/mcp` using OAuth. It does not
store social-account credentials in the plugin. Use of the hosted service is
subject to SocialMCP's terms and privacy policy.
